# 杨永兴“一夜持股法”可验证版

## 概述

本 skill 用于把网络流传的杨永兴“一夜持股法”转化为可执行、可回测、可复盘的 A 股短线策略。

策略基本结构是：

1. 在当日主要走势已经形成后，于 14:25 左右执行市场环境守门；
2. 在 14:30—14:50 从热门板块中筛选成交活跃度居前、近期量能持续、分时强势且尾盘缩量回踩仍有承接的股票；
3. 仅对全部条件达标的标的形成隔夜观察信号；
4. 次日 9:30—10:00 按统一纪律退出，不把隔夜交易转成长线持仓；
5. 通过高频、小幅、可重复的正期望积累收益，而不是追求单笔暴利。

本策略的实质不是“消除风险”，而是减少日内暴露时间，并博弈强势资金的隔夜延续和次日早盘溢价。它会把一部分风险转化为无法在夜间处理的跳空、公告、外围市场和次日流动性风险。因此，任何实盘提醒都必须附带失效条件，且未经回测验证不得描述为确定机会。

## 适用场景

在以下情况下加载本 skill：

- 用户提到“杨永兴”“一夜持股法”“尾盘买、次日早盘卖”；
- 需要在 14:25—14:50 做 A 股尾盘隔夜候选筛选；
- 需要把尾盘强势、分时均价线、缩量回踩、次日早盘退出等口头规则量化；
- 需要设计该策略的历史回测、模拟盘、日报、盘中提醒或复盘系统；
- 需要研究隔夜溢价、开盘退出、尾盘承接和市场阶段之间的关系。

默认边界：

- 本策略是独立策略，不自动关联、补充或修改屠龙战术；
- 不把其他策略的候选池直接当成本策略候选池；
- 不输出“必须买入”“保证收益”等确定性投资建议；
- 只输出观察信号、触发条件、失效条件和风险提示；
- 未经历史验证，不直接部署成自动交易。

## 策略状态机

每个交易日按以下状态推进：

```text
WAIT_MARKET_GATE
  ├─ 市场守门失败 → NO_TRADE
  └─ 市场守门通过 → BUILD_CANDIDATES

BUILD_CANDIDATES
  ├─ 基础过滤失败 → REJECTED
  └─ 基础过滤通过 → WATCH_TAIL_SESSION

WATCH_TAIL_SESSION
  ├─ 14:30—14:50 出现合格触发 → OVERNIGHT_SIGNAL
  ├─ 出现失效条件 → CANCELLED
  └─ 14:50 前无合格触发 → NO_SIGNAL

OVERNIGHT_SIGNAL
  └─ 次日开盘 → EXIT_WINDOW

EXIT_WINDOW
  ├─ 触发风险退出 → EXITED
  ├─ 触发冲高兑现 → EXITED
  └─ 10:00 仍未退出 → FORCE_EXIT
```

不得跳过市场守门，也不得因为当日没有候选而降低过滤条件。

## 一、14:25 市场环境守门

### 基础原则

策略只适合指数相对平稳、市场流动性正常、短线情绪没有明显退潮的交易日。市场守门失败时，当日整体空仓，不再进行个股补票。

### V0.2 可执行条件

当前版本可将“市场平稳或小涨”量化为：

- 采集并展示上证指数及主要指数当日涨跌幅，不设置固定数值硬阈值；
- 14:25—14:30 时主要指数不处于持续放量下跌状态；
- 指数当前位置明显高于日内最低点，或至少没有继续快速创日内新低；
- 14:00—14:30 未出现连续放量破位；
- 市场上涨家数没有进入极端弱势区；
- 跌停数量、炸板率和高位股亏钱效应没有显著恶化；
- 全市场成交额和目标股票流动性足以支持正常退出。

### 一票否决情形

出现以下任一情况，原则上不参与：

- 主要指数明显单边下跌；
- 全市场跌停数量快速增加；
- 高位股集中炸板、批量跌停或短线情绪明显退潮；
- 尾盘指数放量下破关键支撑；
- 市场成交额显著萎缩，目标风格流动性不足；
- 当日存在尚未消化的重大政策、外围市场或突发事件风险；
- 数据源异常、行情延迟或关键字段缺失，无法完成守门判断。

### 自动守门阈值边界

- 当前自动守门不设置任何数值硬阈值；指数涨跌幅、上涨家数占比、跌停数量、炸板率、高位股亏钱效应、14:00—14:30 指数走势和创新低情况全部采集展示；
- 不得由执行者自行补充绝对阈值，也不得因为某一项市场指标达到临时数值就自动停止个股扫描；
- 未量化指标作为市场风险背景和人工判断依据；在用户确认或历史回测定稿前，不作为扫描程序的自动硬否决条件；
- 关键行情数据缺失、延迟或冲突时仍应停止生成有效信号，因为此时无法完成可靠判断；
- 输出时明确区分“市场风险观察”和“个股条件是否通过”，不能把临时假设描述为正式策略规则。

## 二、基础股票池与排除条件

### 默认股票池

- A 股沪深主板普通股票；
- 默认排除北交所；
- 默认过滤创业板、科创板等 20cm 标的；
- 上市时间不少于 60 个交易日；
- 股票处于正常、连续、可交易状态。

### 默认排除

- ST、*ST、退市整理股票；
- 当日停牌、复牌或交易状态异常；
- 一字板、接近涨停且无法按合理价格成交；
- 当日主要上涨逻辑来自突发公告或事件驱动；
- 成交额过低、盘口稀疏、预期滑点过大；
- 重大公告窗口、监管风险或已知隔夜不确定性明显偏高；
- 尾盘出现异动但无法获得可靠量价数据。

## 三、14:30 基础量化筛选

候选股票原则上同时满足：

| 维度 | V0.2 默认条件 | 说明 |
|---|---:|---|
| 板块热度 | 位于当时热门板块 | 优先参与具有板块联动的方向，不用固定个股涨幅代替板块强度 |
| 个股相对强度 | 板块内相对强势且未进入过度加速区 | 排除板块内明显跟风弱股、临近涨停且难以合理成交的标的 |
| 量比 | > 1 | 表明成交活跃度高于近期常态 |
| 换手率 | 5%—10% | 保持活跃，同时控制过度分歧 |
| 成交额排名 | 14:30 时主板可交易股票累计成交额前 25% | 用相对排名适应市场成交水平，同时保留绝对流动性和滑点检查 |
| 近期强势 | 近 20 个交易日出现有效强势拉升 | 保留短线股性和资金记忆，排除仅由异常成交形成的脉冲 |
| 持续量能 | 前 3 个完整交易日成交量均高于各自 120 日均量线 | 过滤单日脉冲，确认资金活跃具有持续性 |
| 分时强度 | 多数时间位于均价线上方 | 不能只看14:30单一时点 |
| 尾盘状态 | 无明显放量出货 | 排除冲高兑现和诱多 |

量比、换手、分时强度和回踩结构属于长期保留的逻辑维度；表中数值只是 V0.2 默认参数，仍须按市场阶段、市值、行业和波动率做分层回测，不得机械照搬。

### 热门板块的盘中定义

“热门板块”必须使用 14:25—14:30 当时可见的数据识别，不能用收盘后的板块排名倒推。至少综合检查：

- 板块涨幅或相对大盘强度居前；
- 板块上涨家数、站上分时均价线家数具有广度，不是单只权重股拉动；
- 板块成交额或成交活跃度相对近期常态有所提升；
- 板块存在两只以上相互印证的强势股票，核心股没有炸板或尾盘明显转弱；
- 个股在板块内保持相对强势，不能因为板块热门而选择明显跟风股。

板块分类、排名范围和热度阈值必须固定数据口径，并通过样本外验证确定。热门板块是候选池过滤器，不能替代个股量价结构和防追高检查。

### 近 20 日强势拉升

- 近 20 个交易日内至少出现一次当时即可确认的有效强势拉升，用于衡量短线股性和资金记忆；
- “有效强势拉升”可用涨停、大阳线、阶段新高或相对行业显著走强等规则量化，但同一轮回测必须固定定义，不能事后人工挑选；
- 突发公告、复牌、除权或极少量成交造成的异常涨幅不计入；
- 近期强势与连续三日站上 120 日均量线分别衡量价格弹性和量能持续性，不能把其中一个当作另一个的替代品。

### 连续三日站上 120 日均量线

- 默认使用扫描日前 3 个完整交易日，即 D-3 至 D-1；每个交易日成交量均高于当时可获得的 120 日平均成交量；
- 若需要把扫描当日纳入判断，只能用 14:30 累计成交量与历史同一时点累计成交量比较，不能读取当天收盘总成交量；
- 均量计算不得引用未来数据，并应使用统一的复权、停牌和异常成交处理口径；
- 连续放量只说明资金活跃持续，不自动等于吸筹；若价格高位滞涨、放量下跌或尾盘出现派发结构，仍须排除。

### 成交额排名与可成交性

- 成交额前 25% 使用 14:30 当时的累计成交额，对主板正常可交易股票横截面排序；
- 相对排名不能替代绝对流动性检查。即使进入前 25%，预计滑点、盘口深度或成交额仍不足以支持计划仓位时也应排除；
- 总市值仅作为记录和分组回测字段，不设固定区间，用于识别超大盘低弹性或小盘高冲击成本造成的差异；
- 不得使用收盘后的全日成交额排名回填 14:30 候选。

## 四、分时强势的量化定义

“全天股价在均价线上方运行”容易产生事后解释，当前统一为：

- 10:00—14:30 期间，分钟收盘价位于分时均价线上方的比例不低于 70%；
- 14:30 时最新价仍位于分时均价线附近或上方；
- 当日走势不能存在已经确认的结构性破位；
- 尾盘回踩期间不能持续放量跌破分时均价线；
- 回踩低点原则上不低于前一段关键低点；
- 若短暂跌破均价线，应在 2—3 分钟内收回，否则视为承接不足。

“均价线上方分钟比例”必须使用当时可获得的数据计算，不能使用收盘后修正的数据倒推盘中信号。

## 五、14:30—14:50 尾盘触发

候选通过基础过滤后进入观察，不代表立即形成参与信号。只有出现完整的“拉升—回踩—承接”结构才触发。

### 合格触发条件

1. 14:30 前后出现一段有效主动拉升；
2. 拉升具有成交量配合，不是单笔成交造成的瞬时脉冲；
3. 拉升有效创出日内新高或突破盘中整理平台，随后回踩分时均价线、突破位或其他明确支撑；
4. 回踩成交量相对拉升阶段明显收缩；
5. 回踩没有有效跌破分时均价线或关键支撑；
6. 回踩结束后出现重新向上的价格承接；
7. 主动买盘、大单承接和盘口稳定性没有明显转弱；
8. 所属行业或题材没有同步退潮，最好存在一定板块联动；
9. 触发时间不晚于 14:50。

### 创新高回踩 V0.2

“创新高”必须在信号发生时即可确认，可采用日内新高或盘中整理平台突破，不用事后可见的收盘位置解释。形成观察信号时还应满足：

- 创新高或突破由连续成交推动，不是孤立的大单脉冲；
- 回踩期间成交量相对拉升阶段收缩；
- 回踩没有有效跌破分时均价线或突破位；允许短暂触碰或轻微跌破，但须在 2—3 分钟内收回；
- 重新介入的确认点是回踩后再次出现主动承接，而不是第一次触碰均价线时直接猜底；
- 若从新高回落至均价线的幅度过大、速度过快或伴随放量，应视为冲高回落而不是合格回踩。

### 缩量回踩 V0.2

当前默认定义为：

> 回踩阶段的分钟平均成交量不高于此前拉升阶段分钟平均成交量的 60%—70%。

具体采用 60%、65% 或 70%，需要通过参数敏感性测试确定，不得挑选单一最优参数后直接实盘。

### 不破均价线 V0.2

允许价格短暂触碰或轻微跌破均价线，但：

- 连续 2—3 根分钟线不能稳定收在均价线下方；
- 跌破时不能伴随明显放量；
- 收回后应重新出现主动承接；
- 若收回仅由单笔拉升完成、后续没有跟随，不算有效回收。

## 六、尾盘取消与失效条件

观察过程中出现以下任一情况，取消信号：

- 14:50 后才突然直线拉升；
- 临近 14:55 才出现无铺垫急拉；
- 尾盘上涨放量，但主动买盘没有持续性；
- 冲高后连续出现明显大单抛压；
- 股价跌破分时均价线后无法快速收回；
- 尾盘创出日内新低或破坏日内上升结构；
- 个股相对板块已经过度加速、临近涨停或进入难以合理成交的追高区；
- 所属板块冲高回落、核心股炸板或联动消失；
- 上涨主要由未经确认的突发消息推动；
- 买一至买五承接不足，盘口波动异常；
- 行情数据延迟、缺失或不同数据源冲突；
- 预计实际成交滑点会显著破坏策略盈亏比。

触发取消后，当日不因股价再次瞬时拉升而自动恢复；如需恢复，必须重新完成完整的量价确认。

## 七、次日 9:30—10:00 退出纪律

### 总原则

- 次日开盘半小时是统一退出窗口；
- 最迟 10:00 完成退出；
- 不因浮亏把隔夜交易转成长线持仓；
- 不以“可能反弹”为由取消风险纪律；
- 回测和实盘记录必须使用可成交价格，而不是窗口内最高价。

### A. 明显高开

例如高开超过 2%：

- 竞价明显过强但开盘承接转弱时，优先兑现；
- 开盘快速冲高时可按预先定义的规则分批退出；
- 冲高后跌破开盘价、分时均价线或短时支撑时退出；
- 不追求卖在最高点；
- 最迟 10:00 退出。

### B. 平开或小幅高开

- 观察开盘后的第一轮冲高；
- 无量冲高、跌破开盘价或承接转弱时退出；
- 9:45 仍无明显上攻时降低预期并优先完成退出；
- 最迟 10:00 退出。

### C. 低开

- 不把低开自动解释为“洗盘”；
- 低开后无法快速收复开盘价时，优先退出；
- 继续放量走弱或跌破预设风险线时执行风险退出；
- 即使浮亏，也不得转为中线或长期持仓；
- 最迟 10:00 退出。

### D. 跌停或流动性异常

这属于该策略无法通过常规止损完全消除的尾部风险。复盘必须单独记录：

- 次日最大不利跳空；
- 9:30—10:00 无法按合理价格成交的次数；
- 跌停、重大公告或流动性枯竭造成的异常亏损；
- 实际成交价与理论信号价之间的滑点。

## 八、仓位与组合风控

当前风控原则：

- 每日候选宁缺毋滥，建议同时形成的有效信号不超过 1—3 只；
- 单票仓位设上限，不能因“隔夜时间短”而重仓单一股票；
- 同一行业或题材不得过度集中；
- 不使用杠杆验证未经证明的策略；
- 计算收益时必须计入佣金、印花税、过户费和滑点；
- 单日策略账户回撤达到 2% 后，停止新增信号；
- 连续 3 笔亏损，可暂停下一交易日并检查市场阶段；
- 5 个交易日累计回撤达到 4%—5%，暂停策略并复盘；
- 出现异常隔夜跳空损失，应优先检查事件过滤和仓位上限。

网络版本中的“单日回撤超过 2%，强制空仓 3 天”可以作为对照风控模型回测，但不预设为唯一正确答案。需要比较固定暂停、连续亏损暂停和滚动回撤暂停的效果。

## 九、回测规范

### 禁止的回测方式

- 使用次日最高价作为默认卖出价；
- 用收盘后才知道的信息筛选 14:30 候选；
- 忽略停牌、涨跌停和无法成交状态；
- 忽略交易成本与滑点；
- 只保留成功信号或人工删除失败样本；
- 事后主观判断“这是洗盘”“这是主力吸筹”；
- 在同一数据集反复调参后只报告最优结果。

### 最低退出模型

至少并行测试：

1. **模型 A：** 次日 9:30 开盘可成交价退出；
2. **模型 B：** 次日 9:35 附近的可成交均价退出；
3. **模型 C：** 9:30—10:00 按明确条件退出，10:00 强制退出。

可增加但不能替代上述基准的模型：

- 高开分批兑现；
- 跌破开盘价退出；
- 跌破分时均价线退出；
- 9:45 时间止盈/止损；
- 按开盘五分钟量价承接调整退出。

### 必须统计的指标

- 总样本数和有效交易日数；
- 胜率；
- 单笔平均收益和收益中位数；
- 平均盈利、平均亏损和盈亏比；
- 最大单笔盈利与最大单笔亏损；
- 最大连续亏损次数；
- 最大回撤；
- 次日高开、平开、低开的比例；
- 次日最大不利跳空分布；
- 交易成本和滑点后的净收益；
- 无法正常成交的样本数；
- 不同市场环境、行业、市值和波动率下的分组结果；
- 参数变化后的稳定性，而不是单一参数最优值。

### 必须设置的对照组

至少与以下基准比较：

- 同股票池随机尾盘买入；
- 仅按当日涨幅筛选；
- 仅按尾盘站上均价线筛选；
- 去掉热门板块条件；
- 去掉近 20 日强势拉升条件；
- 去掉连续三日站上 120 日均量线条件；
- 使用固定市值区间替代成交额前 25% 条件；
- 去掉换手率条件；
- 固定次日开盘退出与条件退出。

只有当完整规则在样本外、计入成本后显著优于对照组，才说明其可能具有独立预测价值。

## 十、重点验证问题

每轮复盘优先回答：

1. 热门板块条件是否优于固定个股涨幅区间，且能否避免选择板块内跟风股？
2. 板块热度应使用哪些盘中指标，阈值在不同市场阶段是否稳定？
3. 近 20 日强势拉升应如何定义，是否具有独立于板块热度的预测价值？
4. 连续三日站上 120 日均量线是否减少一日游，还是增加高位放量后的回撤风险？
5. 14:30 成交额前 25% 是否具有独立价值，是否仍需按绝对成交额或市值分层？
6. 量比 > 1 与连续三日放量、成交额排名之间是否存在过多信息重叠？
7. 换手率 5%—10% 是否应按市值、行业或市场阶段分层？
8. 尾盘站上均价线和创新高后缩量回踩是否具有独立预测价值？
9. 固定早盘退出是否优于条件退出？
10. 强势、震荡和退潮行情中的期望收益，以及实际滑点后的净收益，是否稳定？

## 十一、标准输出格式

盘中输出按单股块呈现，不将多个股票混成一句话：

```text
【一夜持股法观察】股票名称（代码）
时间：14:xx
状态：候选 / 等待回踩 / 触发 / 取消
涨跌幅：x.xx%
成交额：x.xx亿元
成交额排名：主板前 xx%
量比：x.xx
换手率：x.xx%
近20日强势：有效拉升类型及日期 / 未通过
近三日量能：连续站上120日均量线 / 未通过
总市值：xx亿元（仅记录，不作固定区间过滤）
热门板块：xxx
板块状态：强势延续 / 分化 / 转弱
分时强度：均价线上方分钟占比 xx%
尾盘结构：创新高或突破 → 缩量回踩均价线/突破位 → 承接/未确认
观察区：xx.xx—xx.xx
失效条件：跌破均价线并连续N分钟未收回 / 板块转弱 / 放量破位
隔夜风险：公告、跳空、流动性及大盘风险
结论：仅为策略观察信号，不构成确定性交易建议
```

市场守门失败时输出：

```text
【一夜持股法｜今日空仓观察】
时间：14:25
市场守门：未通过
原因：指数尾盘走弱 / 情绪退潮 / 跌停扩散 / 流动性不足 / 数据异常
结论：今日不生成隔夜参与信号，不因个股异动人工补票。
```

次日退出提醒输出：

```text
【一夜持股法｜次日退出观察】股票名称（代码）
开盘状态：高开 / 平开 / 低开，幅度 x.xx%
当前状态：冲高承接 / 无量冲高 / 跌破开盘价 / 放量走弱
风险线：xx.xx
时间纪律：最迟10:00结束本次隔夜观察
说明：不得把隔夜策略转成长线持仓。
```

## 十二、数据与实现要求

- 历史回测优先使用可还原当时状态的分钟级行情；
- 板块热度、成交额排名、近三日成交量、120 日均量、换手率、量比和市值字段必须标注数据日期与盘中时间；
- 盘中扫描不得读取未来分钟或收盘后修正字段；
- 数据源发生冲突时，以更权威、时间戳更明确的来源复核；
- 盘中行情缺失时宁可不发信号，不用旧数据补齐；
- 实盘化前依次经过：历史回测 → 样本外验证 → 模拟盘 → 小规模人工确认；
- 自动化系统默认只发送提醒，不直接下单。

## 常见误区

1. **把尾盘买入理解为没有风险。** 实际上只是缩短日内暴露，并增加隔夜无法退出的风险。
2. **只看热门板块、成交额和量比。** 个股相对强度、持续量能、尾盘结构、盘口承接和市场阶段同样重要。
3. **看到拉升就立即触发。** 必须等待回踩与承接确认，14:50 后急拉默认排除。
4. **用次日最高价计算收益。** 应使用按规则可成交的价格，并计入成本和滑点。
5. **低开后擅自转成长线。** 隔夜策略必须保持退出纪律。
6. **没有候选时人工补票。** 宁可空仓，不因频率目标降低条件。
7. **把网络战绩当作策略证明。** 个人经历与具体收益数字需要可靠来源核验，不能替代完整样本回测。
8. **与其他策略混池归因。** 本策略的候选、交易和收益必须独立记录，默认不计入屠龙或其他策略胜率。
