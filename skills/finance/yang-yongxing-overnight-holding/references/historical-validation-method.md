# “一夜持股法”历史数据验证方法

## 文档定位

本文用于验证“一夜持股法”中的筛选维度、参数阈值、尾盘触发和次日退出规则是否具有稳定的样本外价值。

验证目标不是从历史数据中挑出收益最高的一组参数，而是回答以下问题：

1. 每项条件是否具有独立筛选价值；
2. 参数在哪个范围内表现稳定；
3. 参数是否需要按市场阶段、市值、行业或波动率分层；
4. 不同条件之间是否存在信息重复；
5. 计入真实交易成本和无法成交风险后，策略是否仍有正期望；
6. 结论能否在未参与调参的样本外时期复现。

在完成历史回测、样本外验证、模拟盘和小规模人工确认前，不把任何参数描述为已经定稿，也不部署自动交易。

## 一、验证总原则

### 1. 保留逻辑，检验参数

板块联动、成交活跃、近期量能持续、分时强势、缩量回踩和重新承接是待验证的逻辑维度。历史检验既要比较具体参数值，也要通过消融实验判断某个维度是否应保留。

### 2. 严禁未来数据

历史回放必须严格还原信号时点：

- 14:25 的市场判断只使用截至 14:25 可见的数据；
- 14:30 的板块热度、成交额、换手率、量比和 VWAP 只使用截至 14:30 的数据；
- 14:30—14:50 按分钟顺序识别拉升、突破、回踩和重新承接；
- 不使用收盘后的板块排名、全天成交额、最终最高价或事后修正结果倒推盘中信号；
- 信号产生后使用下一笔或下一分钟可成交价格模拟买入，不使用信号触发前的理想价格；
- 次日退出使用规则能够实际成交的价格，不使用 9:30—10:00 区间最高价。

### 3. 先固定成交模型

调参前先固定以下口径，否则参数结果无法公平比较：

- 信号确认时点；
- 买入延迟和成交价模型；
- 次日退出模型；
- 佣金、印花税、过户费和滑点；
- 涨跌停、停牌、盘口不足和无法成交的处理方式；
- 单票仓位、组合持仓上限和同板块集中度。

### 4. 优先寻找稳定区间

选择参数时优先考虑样本外稳定、回撤可控、附近参数同样有效的区域。若只有一个孤立参数表现很好，而相邻参数明显失效，默认将其视为过拟合风险，而不是最佳参数。

### 5. 预先冻结实验方案

每轮回测开始前建立实验登记，冻结以下内容：

- 数据版本、股票池和时间范围；
- 待测条件、参数候选范围和组合总数；
- 主评价指标、辅助指标和参数通过标准；
- 买入、退出、交易成本和仓位模型；
- 对照组、样本切分方式和随机种子；
- 缺失数据、异常行情和无法成交的处理规则。

实验开始后不得根据中途结果扩大参数范围或更换主评价指标。确需修改时，应建立新的实验编号，并保留原实验结果。最终冻结集一旦打开，不得再用于调参。

### 6. 分离入选规则和退出规则

先使用固定退出模型验证入选信号是否具有预测价值，再冻结入选规则并单独研究退出方式。若同时优化选股和卖出规则，无法判断收益改善来自哪一部分，也更容易产生过拟合。

## 二、数据要求

历史数据应覆盖完整牛市、震荡市、下跌市及高低流动性阶段。数据长度不能只按“三至五年”机械判断，还要同时满足交易制度可比、有效信号数量充足并具备合理统计功效。数据集应尽量包含：

- A 股历史分钟行情、日线行情和复权因子；
- 历史证券状态、上市日期、停复牌、ST 和退市整理标记；
- 当时有效的行业或题材归属，避免用当前成分股回填历史；
- 指数分钟行情、市场上涨家数、跌停和短线情绪字段；
- 历史涨跌停价格、实际可交易状态和盘口流动性；
- 盘中累计成交额、成交量、换手率和可复算 VWAP 的字段；
- 当时可见的流通股本和市值，避免用当前股本回填历史换手率；
- 公告、除权、复牌等异常事件标记；
- 真实交易日历。

必须检查并记录股票池幸存者偏差、行业成分回填、分钟线缺失、时间戳错位和复权处理差异。

### 数据质量门禁

每次回测前至少执行以下检查：

- 分钟时间戳无重复、倒序和跨交易时段记录；
- 累计成交量和累计成交额原则上单调不减；
- 使用成交额与成交量重新计算 VWAP，并与数据源字段抽样核对；
- 14:25、14:30、14:50 和次日退出窗口的关键分钟完整；
- 历史行业、ST、停复牌、涨跌停和上市状态使用当时有效口径；
- 对代表性交易日使用第二数据源复核价格、成交额、VWAP 和股票池数量。

某交易日的分钟行情或横截面股票覆盖率不足时，应标记为“数据无效日”，不能记作“没有信号”。缺失样本数量、缺失原因和分布必须单独报告，并检查缺失是否集中在涨停、跌停、复牌或极端行情股票。覆盖率门槛应在实验登记中预先固定。

## 三、逐日事件回放

每个历史交易日按策略状态机逐步回放：

1. 14:25 生成市场风险背景，不设置未经确认的数值硬守门；
2. 14:25—14:30 使用当时数据识别热门板块；
3. 14:30 对主板正常可交易股票计算基础条件；
4. 对基础候选逐分钟观察至 14:50；
5. 只有完整出现“拉升或突破—缩量回踩—重新承接”才记录信号；
6. 按下一时点可成交价格模拟建仓；
7. 次日按预先固定的退出模型模拟成交；
8. 记录未成交、部分成交、跌停和流动性异常；
9. 当日信号超过组合上限时，按预先固定的排序规则选择标的；
10. 输出每个条件的通过、失败原因和当时使用的数据时间戳。

每日回放应保存完整候选漏斗：股票池数量、板块过滤后数量、基础候选数量、尾盘观察数量、最终信号数量和实际可成交数量。

同一交易日出现的多只股票通常具有共同市场和板块暴露，不能全部视为相互独立的统计样本。回放结果必须同时形成单笔交易记录和交易日组合记录，并明确每日最多持有数量、排序方式、权重、同板块集中度及资金不足时的分配顺序。

## 四、参数验证方法

### 1. 单参数敏感性测试

固定其他条件，每次只改变一个参数，观察结果是否形成连续、合理的变化。示例：

| 参数 | 建议测试范围 |
|---|---|
| 热门板块排名 | 前 10%、20%、25%、30%、40% |
| 板块上涨家数占比 | 50%、55%、60%、65%、70% |
| 板块站上 VWAP 家数占比 | 50%、55%、60%、65%、70% |
| 板块强势股数量 | 1、2、3、按成分股比例计算 |
| 量比 | 0.8、1.0、1.2、1.5 |
| 换手率 | 3%—8%、5%—10%、5%—15% 等 |
| 14:30 成交额排名 | 前 10%、20%、25%、30%、40% |
| 分钟价格位于 VWAP 上方比例 | 60%、65%、70%、75%、80% |
| 近期强势观察窗口 | 10、15、20、30 个交易日 |
| 连续放量天数 | 2、3、4、5 日 |
| 均量周期 | 20、60、90、120 日 |
| 回踩量与拉升量之比 | 50%、60%、65%、70%、80% |
| VWAP 下方容忍时间 | 1、2、3、4、5 分钟 |
| 尾盘触发截止时间 | 14:45、14:50、14:55 |
| 次日最迟退出时间 | 9:45、10:00、10:30 |

单参数结果应同时展示收益、风险、信号数量和分年度表现，不能只展示累计收益。

参数范围、步长和测试组合必须在实验开始前冻结。若结果提示需要扩展范围，应作为下一轮独立实验，不得直接并入原实验后只报告新的最佳值。

### 2. 组合参数测试

参数之间可能存在交互，完成单参数和消融筛选后，再对少量关键组合做网格或分层测试：

- 板块排名 × 上涨家数占比；
- 量比 × 连续放量天数；
- 换手率 × 市值；
- VWAP 上方比例 × 回踩缩量比例；
- 回踩深度 × 收回时间；
- 买入确认方式 × 次日退出模型。

不要一次联合优化大量参数。组合数量过多会显著提高从噪声中选出偶然最优结果的概率。

### 3. 消融实验

以完整策略为基准，每次删除一个条件并重新回测：

- 去掉热门板块；
- 去掉量比；
- 去掉换手率；
- 去掉近 20 日强势；
- 去掉连续三日站上 120 日均量线；
- 去掉成交额排名；
- 去掉 VWAP 上方比例；
- 去掉缩量回踩；
- 去掉重新承接确认。

若删除某条件后收益、回撤和尾部风险几乎不变，但信号数量大幅增加，说明该条件可能没有独立价值。若删除后样本外期望收益或风险表现稳定恶化，才说明该条件可能提供增量价值。

### 4. 对照组实验

至少设置以下基准：

- 同股票池随机尾盘买入；
- 仅按当日涨幅筛选；
- 仅要求尾盘站上 VWAP；
- 只满足个股条件、不要求热门板块；
- 热门板块中的跟风股；
- 热门板块中的相对强势股；
- 固定次日开盘退出；
- 条件退出并在 10:00 强制退出。

随机对照还应增加同日匹配基准：为每个信号匹配同一交易日、相同行业、相近市值、成交额、换手率和当日涨幅，但不满足目标条件的股票。这样可以区分策略规则的增量价值与“买入当日已经强势、活跃的股票”本身带来的收益。

可增加安慰剂测试，例如将信号日期错移一个交易日、在同日匹配池中随机替换股票或随机扰动触发时间。只有完整规则在样本外、计入成本后稳定优于简单基准、匹配基准和安慰剂结果，才说明复杂规则可能提供独立价值。

## 五、热门板块专项验证

热门板块条件应单独拆分为以下层级：

1. 个股条件通过，但不要求所属板块热门；
2. 个股条件通过，且所属板块强度居前；
3. 在第 2 层基础上要求板块具有上涨广度；
4. 在第 3 层基础上要求板块成交活跃度提升；
5. 在第 4 层基础上要求至少两只强势股相互印证；
6. 区分板块核心股与明显跟风股。

专项验证至少比较：

- 行业涨幅使用平均数、中位数还是市值加权值；
- 使用绝对涨幅还是相对大盘强度；
- 板块前 10%、20%、25%、30% 的稳定性；
- 上涨家数和站上 VWAP 家数是否有独立增量价值；
- “至少两只强势股”与“强势股占成分股比例”哪个更稳定；
- 板块成交额相对近期常态提升的观察周期和阈值；
- 行业板块、申万一级或二级行业、题材概念板块的适用差异；
- 板块最少成分股数量；
- 核心股炸板、转弱和板块联动消失的可量化定义。

当前“前 25% + 上涨家数 55% + 站上 VWAP 家数 55% + 至少两只涨幅 3%”仅作为待验证的工程初始值，不作为正式规则或行业标准。

## 六、样本外与滚动验证

### 1. 数据拆分

将数据按时间顺序分为：

- 训练集：探索参数范围；
- 验证集：选择稳定参数区域；
- 测试集：最终只运行一次，不再根据测试结果修改参数。

禁止随机打乱日期后划分训练和测试，因为市场状态具有时间依赖性。

### 2. 嵌套滚动验证

优先采用嵌套滚动方式，例如：

```text
内层训练集：探索参数范围
内层验证集：选择稳定参数区域
外层测试集：评价本轮固定参数
窗口向后滚动后重新执行
```

每个外层测试窗口只能使用之前时间段选出的参数。由于当日信号的收益要到次日上午才完成，训练、验证或测试边界处至少隔离一个交易日，确保前一阶段最后一笔交易的退出数据不会进入下一阶段；如果未来延长持有期，隔离期应同步延长。

最后保留最近 6—12 个月作为完全未参与调参的最终冻结集。每个滚动窗口都应记录所选参数、样本外表现和参数变化幅度。

## 七、分层验证

### 1. 市场阶段

分别检查：

- 上涨、震荡、下跌市场；
- 高成交额与低成交额阶段；
- 高波动与低波动阶段；
- 题材活跃与权重主导阶段；
- 指数上涨、平盘和下跌交易日；
- 板块普涨与少数核心股拉动的交易日。

目标不是要求策略在所有阶段都赚钱，而是明确适用环境、失效环境和是否需要减少参与。

### 2. 股票特征

分别按以下维度统计：

- 总市值和流通市值；
- 行业；
- 股价；
- 日均成交额；
- 波动率；
- 换手率；
- 板块核心股和跟风股；
- 不同涨跌停制度及交易规则阶段。

分层结果用于判断统一阈值是否合理，不能在看到结果后随意切分出表现最好的小组。

市场阶段和股票分层的定义必须在实验前固定，并尽量使用信号时点可见的数据。使用事后信息划分的阶段只能用于解释结果，不能直接转化为盘中守门规则。

### 3. 交易日组合

除单笔交易外，还必须按真实资金约束构建每日组合：

- 分别模拟每日最多 1、2、3 只；
- 候选超限时使用固定排序，不能事后选择收益较高者；
- 比较等权、固定单票上限和同板块限额；
- 统计组合日收益、净值、最大回撤和资金利用率；
- 检查收益是否集中在同一天、同一行业或少数个股。

策略是否可用应以可执行的组合净值为主要依据，单笔平均收益只作为归因指标。

## 八、交易成本与可成交性

至少设置正常、较差和极端三档成交假设，纳入：

- 佣金、印花税和过户费；
- 买入、卖出滑点；
- 信号确认后的成交延迟；
- 以信号后下一分钟 VWAP 或更保守价格成交，禁止直接使用触发分钟收盘价；
- 涨停附近无法买入；
- 次日低开、跌停或流动性不足；
- 计划仓位对盘口和成交额的冲击；
- 单笔成交量参与率上限和组合资金容量；
- 停牌、除权、复牌和公告异常。

若略微提高滑点或延迟后策略即失去正期望，说明策略对理想成交过度敏感，实盘价值有限。

若历史数据只有分钟 OHLCV、没有逐笔成交和盘口，应明确模拟能力边界，并采用保守成交假设，不能声称已经精确还原排队、盘口承接或大单冲击。

## 九、统计稳定性

可采用以下方法：

- 按交易日或月份执行分块 Bootstrap，估计平均收益、胜率和最大回撤的不确定区间；
- 参数扰动测试，检查相邻参数是否同样有效；
- 随机打乱信号日期或股票，构造随机基准；
- 对多参数显著性检验使用 Benjamini–Hochberg 等多重检验修正；
- 对最终候选报告 Deflated Sharpe Ratio，参数组合较多时评估回测过拟合概率 PBO；
- 检查最少样本数以及信号在月份、行业和个股之间是否过度集中。

统计显著不等于可交易；最终结论还要同时满足经济意义、交易成本和尾部风险要求。

## 十、评价指标

每个实验至少记录：

- 总信号数、有效交易日数和每月信号分布；
- 扣除成本后的平均单笔收益和收益中位数；
- 胜率；
- 平均盈利、平均亏损和盈亏比；
- 单笔收益期望；
- Profit Factor；
- 最大回撤；
- 最大连续亏损次数；
- 最差 1% 和 5% 交易结果；
- 次日最大不利跳空；
- 无法正常买入或退出的次数；
- 不同年份、市场阶段、行业、市值和波动率下的一致性；
- 参数变化后的稳定性。

组合层面还必须记录：

- 每日组合净收益和年化波动；
- 组合 Sharpe 或其他风险调整后收益；
- 资金利用率和候选超限次数；
- 行业集中度和单日收益集中度；
- 正常、较差、极端三档成交假设下的容量与收益变化。

评价时不能仅凭胜率或累计收益下结论，也不能把样本内最优结果作为正式参数。

## 十一、参数与条件的通过标准

每轮实验必须在运行前登记主评价指标和通过标准。标准的具体数值由正式回测方案确定，但至少同时覆盖以下维度：

- 样本外扣除成本后的单笔期望收益和交易日组合期望收益为正；
- 收益置信区间、风险调整后收益和经济收益达到预设要求；
- 有效信号覆盖足够的交易日、月份和不同市场阶段；
- 收益不依赖少数股票、行业、月份或极端盈利交易；
- 完整规则相对匹配对照和消融模型具有稳定增量；
- 相邻参数方向一致，不存在孤立最优点；
- 较差滑点和成交延迟情形下没有明显失效；
- 最大回撤、连续亏损和极端跳空风险处于预设容忍范围；
- 外层滚动测试和最终冻结集结论一致；
- 数据覆盖和可成交样本满足预设质量门禁。

条件不满足时，结论只能是“删除”“调整”“分层使用”或“证据不足”，不能因为样本内收益较高而判定通过。最少样本量不使用临时拍定的固定数字，应结合信号频率、收益波动和目标最小可检测效应做统计功效评估，并在实验登记中固定。

## 十二、推荐执行顺序

1. 审计数据质量、时间戳、历史股票状态和横截面覆盖率；
2. 建立实验编号，冻结数据、参数范围、评价指标、通过标准和随机种子；
3. 固定买入模型、三个基础退出模型、交易成本和组合仓位；
4. 逐日回放当前未经调参的原始规则，建立基准结果；
5. 建立随机、简化、同日匹配和安慰剂对照组；
6. 对每条条件执行消融实验；
7. 对具有独立价值的参数做单参数敏感性测试；
8. 对少量关键参数做组合测试；
9. 进行嵌套滚动样本外验证和边界隔离；
10. 按市场阶段、股票特征和每日组合分层检查；
11. 加入正常、较差和极端成交假设，评估容量；
12. 执行分块 Bootstrap、多重检验修正和参数扰动检验；
13. 冻结入选规则后，单独验证次日条件退出；
14. 冻结全部参数后，仅运行一次最终冻结集；
15. 通过后进入模拟盘，不直接自动下单。

最终交付物应同时明确：

- 哪些逻辑维度有稳定增量价值；
- 哪些参数存在可复现的稳定区间；
- 哪些参数应按市场或股票特征分层；
- 哪些条件信息重复或应删除；
- 策略在哪些环境中失效；
- 样本外、计入成本后的收益和风险是否支持继续模拟验证。
