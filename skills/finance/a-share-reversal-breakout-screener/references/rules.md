# A股超跌反转突破筛选规则

## 1. 形态定义

目标形态由四段组成：

```text
长期下跌或深度调整 → 低位止跌/平台 → 均线拐头 → 接近或完成平台突破
```

核心识别对象是趋势状态，不要求当天涨停，也不把低价、小市值设为必要条件。低价小市值代表高弹性风格；大盘股只要满足同样的价格结构，也可以入选，但应单独标注风格。

## 2. 硬过滤

默认全市场扫描使用以下硬过滤：

- 沪深主板代码：`000/001/002/003/600/601/603/605`；
- 排除名称含 `ST`、`*ST`、`退` 的股票；
- 至少有120个有效交易日日线；
- 最新收盘价和成交量有效；
- 当日成交额不低于2亿元；
- 近120日最大峰谷回撤至少20%；
- 最新收盘价位于MA5上方；
- MA5同时高于MA10和MA20；
- MA20高于前一交易日，代表中期均线已经停止下行并出现拐头；
- 最新收盘价至少达到此前20日最高价的95%。

硬过滤用于控制全市场噪音，不表示通过后就是正式候选。

## 3. 指标口径

| 指标 | 口径 |
|---|---|
| 最大回撤 | 最近120日内，按时间顺序计算前高到后续低点的最大跌幅 |
| 平台振幅 | 最新交易日前20日的最高价/最低价减1 |
| MA5/10/20 | 前复权收盘价简单移动平均 |
| 均线方向 | 当前均线与前一交易日的同周期均线比较，与行情软件箭头口径保持一致 |
| 突破比 | 最新收盘价 / 最新日前20日最高价 |
| 量能倍数 | 最新成交量 / 此前20日平均成交量 |
| 相对换手 | 最新成交量 / 此前20日成交量中位数；流通股本短期稳定时等价于换手率相对倍数 |
| 近5日涨幅 | 最新收盘价 / 5个交易日前收盘价减1 |
| MA20乖离 | 最新收盘价 / MA20减1 |
| RSI6 | 国内行情软件常见的6日平滑RSI口径 |
| 收盘位置 | `(收盘-最低)/(最高-最低)` |
| MA60/MA120斜率 | 当前均线相对10个交易日前同周期均线的涨跌幅 |
| 60日突破比 | 最新收盘价 / 最新日前60日最高价 |
| RS20/RS60 | 个股20/60日涨幅减沪深300同期涨幅 |
| 超行业20日收益 | 个股20日涨幅减同行业流动性股票20日涨幅中位数 |
| 行业强度分位 | 各行业20日涨幅中位数在全部有效行业中的百分位，100为最强 |
| 行业宽度 | 行业内收盘价位于MA20上方的股票比例 |
| 平台缩量比 | 最新日前10日均量 / 再前10日均量 |

## 4. 趋势结构

### 完整多头

```text
收盘价 > MA5 > MA10 > MA20
```

且MA5、MA10、MA20均高于前一交易日。

### 早期过渡

```text
收盘价 > MA5
MA5 > MA10
MA5 > MA20
MA20开始上行
```

允许MA10仍低于MA20。该结构用于识别金牛化工式的早期转强，避免完整多头排列成为发现过晚的原因。

### 未完成

仅站上均线、但MA5尚未同时高于MA10和MA20，或MA20仍向下。可以人工观察，但不进入默认脚本候选。

## 5. 评分（100分）

### 回撤深度：15分

- `>=35%`：15分；
- `25%～35%`：10分；
- `20%～25%`：5分。

### 平台质量：15分

- 前20日振幅 `<=15%`：15分；
- `15%～20%`：12分；
- `20%～25%`：8分；
- `>25%`：3分。

### 趋势结构：25分

- 完整多头且三线向上：25分；
- 早期过渡：20分；
- 其他仅站上线结构：10分。

### 平台突破：20分

- 突破比 `>=1.00`：20分；
- `0.98～1.00`：14分；
- `0.95～0.98`：8分。

### 量能：10分

- 量能倍数 `1.3～3.0`：10分；
- `1.0～1.3` 或 `3.0～4.0`：6分；
- `<1.0`：2分；
- `>4.0`：3分并提示高度放量。

### 换手质量：5分

换手必须结合流通市值：

| 流通市值 | 有效换手参考 |
|---|---:|
| `<=50亿元` | `>=4%` |
| `50～150亿元` | `>=2%` |
| `150～500亿元` | `>=1%` |
| `>500亿元` | `>=0.4%` |

同时满足有效换手且相对换手为过去20日中位数的 `1.2～3倍` 得5分；只满足一项得3分。相对换手超过4倍需提示异常分歧。

### 流动性与收盘质量：10分

- 成交额 `>=5亿元`：5分，`2～5亿元`：3分；
- 收盘位置 `>=80%`：5分，`60%～80%`：3分。

## 6. 热度分层

热度独立于趋势评分。满足任一条件即进入对应较高热度：

### 过热

- RSI6 `>=80`；
- 距MA20乖离 `>=15%`；
- 近5日涨幅 `>=20%`。

### 偏热

- RSI6 `75～80`；
- 距MA20乖离 `12%～15%`；
- 近5日涨幅 `15%～20%`。

### 正常

未触发以上条件。

RSI超买不代表趋势立即结束，但候选发现位置偏晚，不应与早期候选混排。

## 7. 二次筛选

二次筛选用于把四层技术候选压缩成重点观察池，不改变“早期 / 确认 / 观察 / 过热”的原始归类。

### 7.1 长周期结构

| 状态 | 条件 |
|---|---|
| 长短共振 | 收盘价 > MA60 > MA120，且MA60、MA120十日斜率均不低于0 |
| MA60转强 | 收盘价 > MA60，且MA60十日斜率不低于0 |
| 长期修复 | 收盘价达到MA60的95%，且MA60十日斜率不低于-1% |
| 长压未解 | 未满足以上条件 |

“长压未解”不是原始形态失效，而是表示20日平台上方仍有较明显的中长期压力。

### 7.2 行业与相对强度

- 用当日成交额达到全市场预筛标准的沪深主板股票计算行业20/60日收益中位数和行业宽度；少于3只有效样本的行业不计算排名。
- RS20、RS60以沪深300为基准；行业强度和超行业收益缺失时明确标记缺失，不按0分伪装成中性。
- 行业强度不改写核心形态得分，只参与二次评分和页面筛选。

### 7.3 量价持续性

- 平台缩量比不高于0.9、当日量能1.2～3倍、收盘位置不低于70%：`缩量后放量`；
- 当日量能1.2～3倍、收盘位置不低于60%：`温和放量`；
- 量能超过4倍或收盘位置低于40%：`量价分歧`；
- 其余为`量价一般`。

### 7.4 基本面与公告风险

最近一期财务指标只作为风险否决和信息提示：

- `风险`：归母净利润、扣非净利润或ROE为负，动态市盈率为负，或通用行业资产负债率不低于90%；
- `关注`：通用行业经营现金流为负、营收同比不高于-20%、扣非利润同比不高于-30%，或通用行业资产负债率75%～90%；
- `正常`：未触发上述条件；
- `数据缺失`：公开接口未返回最近一期数据。

近60日公告按标题检查立案调查、行政处罚、退市风险、重大诉讼/仲裁、债务逾期/违约、股份冻结、减持、限售股流通、业绩预亏和控制权变更等风险词；“解除质押”“解除冻结”不按风险命中。标题匹配只负责提醒，最终仍需阅读公告原文。

### 7.5 二次评分与层级

二次评分满分100，权重为：原技术质量40、行业与相对强度25、长周期20、基本面/公告/量价15。它只用于排序，不替代原始100分技术评分。

`核心观察`同时要求：

- 二次评分不低于70；
- 原阶段为早期或确认，且热度正常；
- 行业强度分位不低于60，RS20不低于0；
- 长周期不是“长压未解”；
- 无基本面硬伤，近60日公告未命中风险关键词。

二次评分不低于55、无基本面硬伤且公告未命中风险关键词的其余候选进入`重点复核`，其他为`一般观察`。公开数据缺失时不能进入核心观察。

## 8. 输出层级

| 层级 | 条件 |
|---|---|
| 早期 | 得分不低于75，早期过渡或接近突破，热度正常 |
| 确认 | 得分不低于75，完整多头且突破比不低于1，热度不为过热 |
| 观察 | 得分65～74，或条件接近但尚待确认 |
| 过热 | 得分不低于65，但触发任一过热条件 |

涨停只记录为 `limit_up=true`，不增加得分，也不改变核心层级；若同时过热，仍进入过热层。

## 9. 风格标签

- 高弹性：股价2～20元且流通市值20～150亿元；
- 小盘：流通市值不超过50亿元；
- 中盘：50～500亿元；
- 大盘：500～1500亿元；
- 超大盘：超过1500亿元。

风格标签不决定技术形态是否成立。比较股票时应分别回答：

1. 技术形态是否相似；
2. 是否属于赤天化/金牛化工式高弹性风格；
3. 当前处于早期、确认还是过热阶段。

## 10. 截图复核模板

逐项输出：

```text
结论：符合 / 基本符合 / 部分符合 / 不符合
阶段：早期过渡 / 完整确认 / 过热加速 / 尚未完成
核心证据：回撤、平台、均线、突破、量价、RSI
缺失数据：截图中无法确认的量能、上市时间或历史窗口
风格标签：高弹性 / 小盘 / 中盘 / 大盘 / 超大盘
降级风险：乖离、RSI、上影、巨量滞涨、基本面
后续确认：突破区、MA10/MA20关系、缩量回踩、量能承接
```

不要仅凭一根大阳线或涨停判断符合；也不要因为没有涨停判定不符合。
